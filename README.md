# VYBEX Website

Free static website prepared for the VYBEX TikTok developer application.

Before publishing:
1. Replace `REPLACE_WITH_YOUR_EMAIL` in `contact.html` with an email address you control.
2. Review the Terms and Privacy Policy for your actual business, data practices and jurisdiction.
3. Publish this folder on a public HTTPS host.
4. Use the live URL in TikTok Developer.
5. Verify the website, Privacy Policy and Terms URLs in TikTok URL Properties.

VYBEX is an independent product and is not affiliated with TikTok.
